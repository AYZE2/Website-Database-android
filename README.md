# Football Club Information App

An Android app that fetches and displays information about football clubs and leagues from a public web service, with local caching and search.

## Features

- Browse football leagues and clubs
- Fetch live club/league data from a web API
- Local data persistence with Room, so data is available offline after first load
- Search functionality across clubs and leagues
- Handles device orientation changes without losing state

## Tech Stack

- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Local storage:** Room (SQLite)
- **Networking:** REST API calls to a football data web service

## Getting Started

1. Clone the repo and open it in Android Studio.
2. Sync Gradle and run on an emulator or physical device.
